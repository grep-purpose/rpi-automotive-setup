# HUDIY-Integration

[integration](integration/) enthält Projektadapter und Konfiguration. Die HUDIY-Anwendung und ihre rechtmäßig bezogenen Laufzeitabhängigkeiten werden weiterhin separat installiert. Das Verschieben dieser Integrationsdateien installiert nichts auf dem Pi.

Der bisherige API-Altbestand bleibt am ursprünglichen Repository-Pfad; er wird hier nicht dupliziert. Der private Ordner scripts/hudiy_api auf dem Pi bleibt unversioniert. [Herkunft und Rechte](../../recovery/HUDIY_SOURCE.md).
