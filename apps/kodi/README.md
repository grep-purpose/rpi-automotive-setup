# Kodi – Oberfläche und Mediencenter

- addons/: vollständige Add-ons und Skins.
- skin/ und skin.estuary.custom/: weitere gesicherte Skin-Stände; nicht automatisch zusammengeführt.
- userdata/, keymaps/ und Konfigurationsdateien: Einstellungen und Eingabezuordnung.
- scripts/: Kodi-gebundene Medien-/USB-/Bluetooth-Adapter.
- weather-tools/: bisher verstreute Wetter-/GPS-Helfer; von vorhandenen Varianten getrennt.

Kodi bleibt zur Laufzeit unter /home/pi/.kodi eingerichtet. Diese Neuordnung ersetzt diese Installation nicht. [Architektur](../../docs/ARCHITEKTUR.md) · [Startseite](../../README.md)
